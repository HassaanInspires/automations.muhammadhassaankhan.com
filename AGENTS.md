# Project Guidelines for Antigravity Agent

## Overview
This workspace is managed using Antigravity CLI. Customizations, skills, and rules are organized in `.agents/` and mirrored across `.gemini/` and `.claude/`.

## Active Skills
- `ui`: Premium UI design, layout recipes, anti-slop rules, and device mockups.
- `antigravity-design-expert`: Motion design, GSAP animations, 3D CSS transforms, and spatial glassmorphism.
